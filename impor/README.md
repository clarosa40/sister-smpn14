# Berkas impor

Taruh Excel daftar pegawai di sini, lalu:

    npm run impor:pegawai -- impor/pegawai.xlsx          # jalan kering
    npm run impor:pegawai -- impor/pegawai.xlsx --tulis  # buat akun

`sandi-sementara.csv` ditulis di folder yang sama dengan Excel-nya.

Seluruh isi folder ini diabaikan git kecuali README ini sendiri -
di sini ada nama asli satu sekolah dan, sesudah --tulis, sandi
sementara mereka dalam teks polos. Bagikan sandinya, lalu hapus
berkasnya.
